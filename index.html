Project Overview

This utility automates library inventory cataloging and circulation tracking. It replaces traditional manual tracking with an optimized, object-oriented in-memory data store engine.

Architectural Design Patterns Applied

  • Singleton Pattern: Enforces a single instance of the database map across the application execution lifespan to guarantee clean synchronization.
  • Facade Pattern: Couples subsystem interactions behind a unified LibraryFacade API interface wrapper.

Execution Instuctions

To run the localized application, clone the repository and run the engine script via the terminal:

python lms.py
